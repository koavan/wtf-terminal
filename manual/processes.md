# Processes

The Processes tab ({{key:sidebar.processes}}) shows what's running.

- **Terminals** (default): a tree of processes under each tab's shell. Click a tab's name to jump to it.
- **All**: every process you own, sorted by CPU, memory or name.
- Right-click a process: **Show Network Connections** (opens [Network](#network) filtered to it), **Copy PID**, **Copy Command**, **End …** (asks the process to quit) or **Force Quit …** — both ask first.

It refreshes only while visible and the window is in front.
